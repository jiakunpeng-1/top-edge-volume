# Changelog

All notable changes to this project are documented in this file.

## 1.2.0 — 2026-11-05

- Add a no-focus on-screen overlay that displays the current volume percentage while adjusting volume and hides shortly after scrolling stops.

## 1.1.1 — 2026-11-01

- Publish a lightweight framework-dependent executable that is about 0.25 MB.
- Document the .NET 8 Desktop Runtime requirement and the optional self-contained build.

## 1.1.0 — 2026-11-01

- Add optional bottom-edge mouse-wheel volume control, enabled by default.

## 1.0.0 — 2026-11-01

- Initial public release.
- Multi-monitor top-edge mouse-wheel volume control.
- Configurable edge height and volume step from the tray menu.
- Optional automatic startup.
- Direct Core Audio volume control with automatic default-device tracking.
